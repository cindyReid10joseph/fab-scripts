# fab-scripts
Repositorio de práctica para scripting y control de versiones utilizando GitHub.

## Descripción
Este proyecto contiene un script en Python para analizar texto ingresado por el usuario.

## Instalación
No requiere instalación adicional si ya se cuenta con Python 3.

## Uso
Ejecutar el archivo con el siguiente comando:
```bash
python text_stats.py```
## Características
- conteo de caracteres
- conteo de palabras
- conteo de líneas
- conteo de espacios
- conteo de vocales
- palabra más larga
- texto en mayúsculas
